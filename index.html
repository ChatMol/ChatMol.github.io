ChatMol Lab

An AI scientist agent that combines NVIDIA BioNeMo cloud tools, 50+ biological databases, code execution, and interactive 3D visualization. Design proteins through natural conversation.

  • 11 BioNeMo NIM tools (ESMFold, OpenFold, Boltz-2, RFDiffusion, DiffDock, etc.)
  • 50+ databases (UniProt, PDB, PubMed, ChEMBL, AlphaFold DB, etc.)
  • Python code execution with BioPython integration
  • Interactive 3D Molstar viewer for structure visualization
